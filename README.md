# VizQon

Penelitian eksperimental untuk merancang dan membangun sebuah purwarupa guna mendeteksi dan menghitung benih ikan secara otomatis dan real time berbasis YOLO dan Computer Vision. Penelitian ini merupakan skripsi daripada penulis yang dikerjakan di Laboratorium Teknologi Kelautan, FPIK Unsoed Purwokerto selama 8 bulan lamanya.
